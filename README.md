# CloudMigrator

Перенос файлов с публичной папки **Mail.ru Облако** на **Яндекс.Диск**.

Работает в двух режимах: через **GitHub Actions** (рекомендуется для больших объёмов) и в **Google Colab**.

---

## Возможности

- Рекурсивно обходит вложенные папки
- Пропускает уже загруженные файлы — безопасно перезапускать после сбоя
- До 4 автоматических повторов на каждый файл при ошибке сети
- Воссоздаёт структуру папок на Яндекс.Диске
- Два режима загрузки: REST API (OAuth, рекомендуется) и WebDAV

---

## Ограничения по скорости и размеру

Mail.ru ограничивает скорость отдачи публичных ссылок для зарубежных IP-адресов (GitHub Actions — США), поэтому скорость скачивания составляет **~0.5–1 МБ/с**.

| Что | Значение |
|-----|----------|
| Скорость скачивания с Mail.ru | ~0.5–1 МБ/с |
| Максимальный размер одного файла | ~3–4 ГБ |
| Суммарно за один запуск (6 ч) | ~8–15 ГБ |
| Лимит времени GitHub Actions | 6 часов |

**Для архивов больше ~10 ГБ** потребуется несколько запусков подряд — уже перенесённые файлы пропускаются автоматически.

## Быстрый старт — GitHub Actions

### 1. Форкни репозиторий

### 2. Получи OAuth-токен Яндекса (нужен для больших файлов)

Без токена загрузка файлов крупнее ~200 МБ завершается ошибкой SSL — Яндекс.Диск WebDAV обрывает соединение на долгих закачках с иностранных IP.

**Как получить токен:**

1. Перейди по ссылке (подставь свой `client_id`):
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
   ```
   Если у тебя нет приложения — создай его на [oauth.yandex.ru](https://oauth.yandex.ru), нужны права `cloud_api:disk.write` и `cloud_api:disk.read`.

2. Разреши доступ → Яндекс перенаправит на страницу с токеном.

3. Скопируй `access_token` из адресной строки или со страницы.

### 3. Добавь секреты

`Settings → Secrets and variables → Actions → New repository secret`

| Секрет | Обязательный | Значение |
|--------|:---:|---------|
| `YA_OAUTH_TOKEN` | ✅ | OAuth-токен (см. выше) — устраняет SSL-ошибки на больших файлах |
| `YA_LOGIN` | нет | Логин Яндекс-аккаунта (для WebDAV-fallback) |
| `YA_APP_PASSWORD` | нет | [Пароль приложения](https://id.yandex.ru/security/app-passwords) Яндекса |

### 4. Запусти Action

`Actions → Mail.ru → Yandex.Disk → Run workflow`

Введи:
- **Ссылка Mail.ru** — публичная ссылка вида `https://cloud.mail.ru/public/...`
- **Папка на Яндекс.Диске** — имя папки назначения (оставь пустым — создастся автоматически)

В логах должно появиться:
```
✅ Авторизация OK  [REST API (OAuth)]
```

## Как это работает

```
Mail.ru API → список файлов
     ↓
для каждого файла:
  если файл уже есть на Яндекс.Диске → пропустить
     ↓
  скачать во временный файл (/tmp)  ← до 4 попыток
     ↓
  загрузить на Яндекс.Диск          ← до 4 попыток (без повторного скачивания)
  (REST API: presigned URL / WebDAV: fallback)
```
